IMPORTANT
This package is a fully connected browser demo, not a production cloud ERP. Data is shared between the website and admin on the SAME browser through localStorage. It is not shared between different laptops/phones.

For production deployment, replace the browser storage layer with a server database/API (MySQL/PostgreSQL), server-side authentication, permissions, audit logs, SMTP, WhatsApp Cloud API, real payment gateway and backups.

Internet is recommended because product/hero images are loaded from Unsplash URLs.
